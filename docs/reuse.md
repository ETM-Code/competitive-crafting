# Reuse decisions

Research and initial measurements, 2026-09-17. Update coverage numbers with `npm run sync:data`.

| Candidate                                         | Decision                                    | Concrete reason / measurement                                                                                                                                                                                                         |
| ------------------------------------------------- | ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| misode/mcmeta canonical 26.3 recipe/tag snapshots | Adopt data                                  | Canonical chest recipe references #minecraft:planks per slot; accepts mixed wood correctly. Versioned release data and assets both available.                                                                                         |
| PrismarineJS/minecraft-data 3.116.0 (MIT)         | Borrow as research oracle, not runtime      | 26.1 has 1,506 items, 887 recipe outputs, 1,684 variants. Flattened uniform-material recipes omit mixed-tag combinations. Older than target version.                                                                                  |
| prismarine-recipe                                 | Reject runtime                              | Inspected implementation: recipe representation, requiresTable and delta, no grid matching. Small correct matcher is the game's core logic.                                                                                           |
| minecraft-inventory-gui (MIT)                     | Reject whole renderer                       | Canvas drawing/event APIs require own interaction logic; responsive semantic 48px touch slots and keyboard accessibility would need a parallel DOM layer. Borrow only visual reference, no code copied.                               |
| Valgard/mcui (MIT)                                | Reference only                              | Old minimal HTML framework; small stone-bevel styling is simpler than integrating unrelated page scaffolding. No substantial engine recreated.                                                                                        |
| EnhancedJax/minecraft-react-crafting              | Reject                                      | No clear code license, React/Three dependencies unnecessary; user explicitly rejected low-quality item imagery.                                                                                                                       |
| Owen1212055/mc-assets                             | Adopt item images, game-art rights retained | Native 256×256 renders through 26.3. Six actual PNGs measured: crafting table 11,347 B; diamond 4,357 B; iron ingot 3,523 B; copper chest 9,449 B; crafter 11,563 B; copper lantern 3,117 B. All 256×256. Full corpus audit scripted. |
| Monocraft                                         | Adopt                                       | SIL Open Font License; pixel typography without distributing proprietary game font.                                                                                                                                                   |
| qrcode / jsqr                                     | Adopt                                       | MIT; generation and independent decoding in QR end-to-end tests.                                                                                                                                                                      |
| Cloudflare native Durable Objects                 | Adopt                                       | Durable per-room serialization and hibernating WebSockets without an additional multiplayer vendor.                                                                                                                                   |
| Spotify iframe API                                | Adopt                                       | User approved official player; track URIs verified in supplied playlist. No audio extraction/hosting.                                                                                                                                 |

GitHub Contents API caps large directories at 1,000 files; sync uses pinned complete tree listings/archives instead. Essential assets are local, not hotlinked. Cache source responses under build/cache. Source manifest records commits/checksums and exclusions. Minecraft game art is not relicensed MIT by a code repository; see THIRD_PARTY_NOTICES.md.
